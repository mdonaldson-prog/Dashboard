# Executive Operations Dashboard

An executive dashboard for KPIs, demand forecasting, cycle count schedules, and vendor/carrier scorecards. It sources data from inFlow Inventory / inFlow Manufacturing through the inFlow Cloud API.

**Status:** Design phase. There is no application code yet.

- [System Design Document](docs/SYSTEM_DESIGN.md): architecture, database schema, component hierarchy, user flows, and the phased implementation plan.
