# Executive Operations Dashboard

An executive dashboard for KPIs, demand forecasting, cycle count schedules, and vendor/carrier scorecards. It runs on inFlow Inventory / inFlow Manufacturing data exports.

It's designed as a single HTML file that reads inFlow export files from a shared folder. There's no server, no accounts, and nothing to maintain beyond a weekly upload of files.

**Status:** Design phase. There is no application code yet.

- [System Design Document](docs/SYSTEM_DESIGN.md): architecture, data model, component hierarchy, user flows, and the phased implementation plan.
